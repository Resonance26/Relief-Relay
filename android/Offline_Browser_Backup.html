How to send tomorrow

  1. Turn on Bluetooth and pair Android with ReliefRelay-Gateway when the ESP32 is powered.
  2. Open a Bluetooth Classic serial-terminal app and connect to the paired gateway.
  3. Copy a saved RR1|... message from the Requests tab.
  4. Paste the message and send with a newline (LF or CRLF).
  5. Check the warehouse dashboard to confirm receipt; the gateway transmit notice isn't proof of delivery.
The native App Inventor project includes a Bluetooth connection button and Send Request action, so manual copying is only a backup path.
